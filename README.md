🌩️ CloudIt

CloudIt is a simple and secure file upload & sharing platform where users can upload files and control access with unique shareable links. It’s designed to make storing and sharing files in the cloud seamless.

✨ Features

📂 Upload files securely

🔗 Generate unique shareable links

👥 Access control (public or restricted)

📱 Responsive UI

🛠️ Tech Stack

Frontend: React ,Tailwind CSS,React Router

Backend: Node.js ,Express

Database: MongoDB (Mongoose)

Cloud Storage: Cloudinary

Authentication: JWT,bcrypt

🚀 Getting Started

1. Clone the repo
   git clone https://github.com/your-username/cloudit.git
  cd cloudit

2. Install dependencies
   npm install
